# 第十章 後山巡境 — Screenplay (`ch10_east`)

> 季節：五月初五（端午）→ 七月廿九夜（頭城搶孤）→ 七月三十黎明（龜山島）。
> 地點：黑潮上的王船 → 蘭嶼（達悟族）→ 台東（寶桑、卑南族巴拉冠青年、阿美族部落與海祭）→ 花蓮（洄瀾、太魯閣族部落、清水斷崖、太魯閣峽谷）→ 中元夜海上 → 宜蘭頭城（搶孤）→ 龜山島。
> 主題：**活的潮與死的潮；橋是走出來的，不是生出來的。** 黑潮慷慨、送來飛魚——它是黑水溝的反面。各族的人有各自的規矩與看法，隊伍學會「在別人的家裡守別人的規矩」。星河在太魯閣得到本作最重要的情感轉折：沒有魂燈的他，第一次相信自己也「過得去」。

### 5.5 謎題：燕子口鹽壩
- 狀態：溪道上三道鹽壩 ①②③（由上游到下游），分隔四個水潭 P0（最上游，水位高）、P1、P2、P3（最下游，接溪口）。每個水潭水位 ∈ {高, 低}。初始：P0 高、P1 高、P2 高、P3 低。
- 通行：主路需經過 P2 與 P3 旁的低窪岩棚；水位「高」時岩棚淹沒不可走。壺穴寶箱在 P1 旁，P1 低時才可走到。
- 輸入：星河對鹽壩使用「心火」（調查 → 選「用心火融開」）。融開鹽壩 n → 上游潭的水流入下游潭：
  - 若下游潭原本「低」：上游潭變「低」，下游潭變「高」。
  - 若下游潭原本「高」：洪水溢出，**沖走玩家回到 B 段入口**（HP −5%），鹽壩重新結起（重置全部狀態），雲歸提示：「下面還滿著，水沒地方去。」
- 解法：先融 ③（P2→P3：P2 低、P3 高——P3 下游即溪口，自然排出，**P3 隨即變回低**），再融 ②（P1→P2：P1 低、P2 高 → 因 ③ 已開，P2 再排到 P3 → P2 低），再融 ①（P0→P1：P0 低、P1 高 → 排至 P2 → P3 → 全低）。即「**先開下游**」。
- 提示：Watan：「水要往下走。先替它把下面的路開好。」
- 失敗無懲罰以外的卡關；可無限重試。

### 6.2 頭目：潮病海蛇（蘭嶼夜灘）
- **外觀**：`tide_serpent`。粗如屋樑，昂首高過人頭；黑色藤壺爬滿身體，鱗片間滲黑水。淨化後鱗片為深藍帶金紋。
- **陣型**：海蛇在左側淺灘；右側隊伍背後是一排拼板舟（背景）。
- **機制「潛水」**：每 3 回合海蛇使用 `es_dive` 潛入水中 1 回合（不可被選為目標），下一回合從隨機一名角色腳下 `es_surge_strike`（單體 phys 2.0）。
  - **王船船頭燈**：陳伯在海上把燈光照向灘頭。潛水回合開始時，畫面上海面會出現一道光照出的影子（顯示即將攻擊的角色頭上 ! 圖示）。該角色若選「防禦」→ 傷害 ×0.5 且海蛇浮出時 `stun` 1 回合（「撞上了！」）。
- **機制「撞船」**：海蛇 HP < 60% 時，每 4 回合嘗試 `es_ram_boats`（撲向拼板舟）。若該回合隊伍中**星河**未被 KO：自動演出「星河擋在船前」，星河承受 phys 1.6 傷害、船安全；若星河 KO：隊伍全體受 phys 1.2（「浪頭掃過灘頭」），無其他懲罰。（劇情上船絕不會被毀。）
- **技能**：`es_bite_big`（單體 phys 1.7 + poison 40%）、`es_tail_whip`（全體 phys 1.0）、`es_black_spray`（全體 mag water 1.1 + defDown 30%）、`es_dive`、`es_surge_strike`、`es_ram_boats`。
- **階段**：P1（100–60%）；P2（<60%）加入撞船、spd +8；P3（<25%）藤壺剝落，def −30%，`es_tail_whip` 連擊兩次。
- **陳伯支援**：P2 開始時一次——「引魂槳・渡」：陳伯在王船上用槳拍水，一道浪把海蛇推回深水，海蛇下一次行動延後（等待時間 +60%）。
- **戰後**：被黑潮洗淨，游走（不殺死）。

### 7.4 文化與寫作備註
- **達悟族（蘭嶼，Ponso no Tao）**：死亡禁忌與 anito（惡靈）觀念以「隊伍身上有死的味道、請留在海邊」呈現，**由達悟人自己說明、自己決定**，隊伍完全遵守。拼板舟（tatala）、船眼紋、親從子名、飛魚（alibangbang）與飛魚季、男人魚／女人魚／老人魚的分類、曬飛魚、飛魚頭目托夢教導規矩的傳說——只寫到一般常見的說法；飛魚季的細部禁忌只寫 Sinan 說的四條，**刻意不展開**（她也說「其他的，你們不用知道」）。不描寫招魚祭、新船下水禮等祭儀。造船只由 Syaman 本人進行，隊伍只在他開口時遞東西、扶木板。部落以名稱不明的「灘頭」呈現。
- **卑南族巴拉冠（palakuan）**：只出現青年晨跑訓練與一位青年的說明；「裡面的事外人不能看」由他本人說出。不描寫猴祭、大獵祭。
- **阿美族（Pangcah）**：年齡階層（青年服從長老、分魚先長老）、海祭（遠觀、無 BGM、玩家無法移動、不寫祝禱內容）、野菜文化（「牛吃的草我們都能吃」為常見的自嘲說法）、阿里鳳鳳、小米酒（一小口）、檳榔待客、問候語 Nga'ay ho。部落名不具名。海祭的具體性別分工只以 Panay「男人去海邊，我們在家裡準備吃的」帶過，並注明「這個部落的規矩」。
- **太魯閣族（Truku）**：紋面（女子以織布技藝、男子以保護家人與狩獵能力而得）、Gaya、彩虹橋 Hakaw Utux、祖靈 Utux、sisil 鳥占（只由 Watan 說明，不演示儀式）、獵場規範、分肉、水平背帶織布機、Mhuway su（謝謝）。依旺明確表示「你們漢人過不過我們的橋，我不知道」——**不把太魯閣族的信仰套到漢人主角身上**，只分享她的人生智慧。彩虹（`rainbow_arch`）只能看，不能走。
- **噶瑪蘭族（Kavalan）**：蕉絲阿姨以香蕉絲織布、族人遷往花蓮一帶的事實帶過，不涉及衝突與政治。
- **人名**：Syapen/Syaman/Sinan Kaswal、Kolas、Panay、Iwan、Watan 為依各族常見命名所取的佔位名；Kaswal 一名建議實作前請熟悉達悟文化者確認。
- **漢人民俗**：端午（艾草菖蒲、立蛋、粽子）、七月初一開鬼門、豎燈篙、中元普渡、放水燈、豬腳麵線做生日、頭城搶孤（十二根孤柱抹牛油、孤棚、孤棧、順風旗、五人一隊、疊羅漢與繩索、倒吊翻棚、割供品拋給群眾、歷史上因傷亡屢遭禁止）——皆依實際習俗描寫。本作不使用頭城真實廟名。
- **日期**：頭城搶孤在傳統上於七月底關鬼門前後舉行；本作安排在七月廿九夜，第十一章為七月三十（關鬼門）。順風旗＋千歲爺之風讓王船一日內從宜蘭繞北到澎湖——第十一章作者請銜接。
- **與第十一章銜接**：`星河的燈籠`（陳伯做的、寫著星河名字的燈籠——「沒有魂燈的人，由別人為他點一盞」，可作真結局「千燈」的意象）、`船眼護符`（「看不到路的時候，它幫你看」——黑水溝上可用）、`依旺的織帶`、`順風旗`、巡境圖全亮、夜念的水燈（陳伯放的）、C10-16 白芷與夜玄的插敘。
