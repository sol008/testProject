# 第七章 雲山入夢

> 季節：早春（正月底～二月）。白芷被擄往玄武嶼，星河體內借來的燈火日漸黯淡。
> 隊伍：星河、紅纓、雲歸（貓咪 芋圓、麻糬 在地圖上同行，從不說話，只用旁白與情緒圖示表現；麻糬在白芷缺席期間一直望著海、守著她綁的紅繩）。白芷缺席。（糰子已依客戶要求刪除。）
> 建議等級：進入 22～23 → 離開 25～26。
> 本章主題：**借來的光要怎麼還？**——答案不是「還」，而是「點亮自己，再把光分出去」。
> 文化重點（遵守 STORY_BIBLE「Cultural accuracy & respect guide」）：鄒族 kuba 與獵人倫理、塔山；布農族 pasibutbut
> （八部合音）只「聽」不「參與」、玉山洪水傳說與紅嘴黑鵯取火；邵族白鹿傳說與杵音；**不去 Lalu、不上塔山**。
> **夢藤湯／入夢禮只屬於虛構隱士藤婆一人**，與任何真實族群無關；所有原住民角色都不知道、也不參與這個儀式。

## 0. 本章系統：燈芯將盡（星河 HP 上限衰減）

| 項目 | 規格 |
|---|---|
| 狀態值 | `flag: ch7_flame`（整數 0～100），本章開場設為 **80** |
| 效果 | 星河最大 HP = 正常最大 HP × `ch7_flame` / 100（無條件捨去）。現有 HP 超過上限時截斷 |
| 衰減 | 每場戰鬥結束（勝利／逃跑皆算）−2；劇情指定時點 −4（文中以 `[燈芯 −4]` 標示） |
| 下限 | 30（燈芯將盡不會直接致死，只會讓他越來越脆弱） |
| 回復 | 在鄒族家屋、布農家屋過夜各 +8（文中以 `[燈芯 +8]` 標示）。「人的溫暖讓燈多亮一刻。」一般藥品**無法**提高上限 |
| UI | 星河 HP 條旁顯示小火苗圖示，大小與亮度隨 `ch7_flame` 變化；低於 50 時火苗會不規則閃爍 |
| 解除 | 靈境中覺醒心火（`flag: ch7_xinhuo`）後移除 `ch7_flame`，星河永久獲得被動「心火」：最大 HP +8%、火屬性傷害 +10% |
| 戰鬥 | 星河 KO 時不額外懲罰；但若星河是最後一個倒下的人，Game Over 畫面文字改為「燈，熄了。」 |

- 廳內五盞石燈座（`stone_lantern`），位置與屬性：北＝水、東北＝火、東南＝木、西南＝金、西北＝土（刻意打亂）。
- 廳中兩幅提示壁畫（不計入心燈 14）：
  - 東牆「春」：「春生於木。木生火，火生土，土生金，金生水，水歸於木。」（正確提示）
  - 西牆「戰」：「金克木，木克土，土克水，水克火，火克金。」（陷阱提示）
- 輸入：調查燈座 → 該燈點燃（需雲歸在隊；調查時顯示雲歸擲出對應的五行符）。
- 解答：依**相生**順序點燃：**木 → 火 → 土 → 金 → 水**。
- 失敗：點錯任一盞 → 全部熄滅。每**第二次**失敗觸發戰鬥 `troop_ch7_moths`（燈蛾×3）。若玩家依**相剋**順序連續點對兩盞（如金→木），額外播放雲歸台詞：「……不對。師父說過，燈要用『生』的方式點，不是用『克』的。」
- 成功：中央水池退去，出現往下殿的 `stairs_down`。
