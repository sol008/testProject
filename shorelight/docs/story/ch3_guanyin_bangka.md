# 第三章　觀音艋舺

> 季節：八月（八月初七 → 八月十五 中秋）。地區：淡水（紅毛城）→ 八里渡口 → 觀音山道 → 太虛觀 → 艋舺。
> 建議等級：10 → 14。開場隊伍：星河、白芷、紅纓。本章加入：雲歸（joinLv 11）＋ 糰子（地圖跟隨／召喚技）。
> 前置旗標：`ch2_done`。結束旗標：`ch3_done`（接第四章 竹塹）。
> 本章要讓玩家記住的真實事物：淡水河口與夕照、紅毛城是西班牙人與荷蘭人留下的古堡、觀音山的「臥佛側臉」與
> 觀音山石（艋舺的廟宇多用這裡的石材）、「艋舺」原是凱達格蘭語「獨木舟」、龍山寺供奉的觀音、青草巷、
> 剝皮寮（剝杉木皮的街）、「一府二鹿三艋舺」、頂郊與下郊之拚（三邑人與同安人）、中秋關椅仔姑、歌仔戲、擲筊。
