## 1. 地圖

### `dream` — 夢境・燈橋

- **用途**：序章教學關。一條由木板與燈籠構成的窄橋，筆直地伸向一片無邊的黑海。
- **尺寸**：21 × 46（64px 格）。
- **玩家起點**：(10, 42)，面向上。（註：`G.newState()` 目前預設 `x:10, y:20`，請新遊戲腳本改為 (10,42)，或直接以本章 0-2 腳本 `S.setPos` 設定。）
- **地形**：除橋與平台外全是 `black_sea`（實心、會動、海面下漂著淡淡的燈光）。橋面 `lantern_bridge`；三個平台用 `cloud` 地形鋪在 `lantern_bridge` 中央（像霧凝成的地面）。
- **時間／光線**：無時間；`light: { ambient: 0.82 }`。光源只有橋上的燈籠（暖橘）、海裡的燈魂（藍白），以及最北端遠方那盞忽明忽滅的大燈（彼岸燈）。
- **粒子**：`motes`（極慢的上升光點）＋ `mist`（貼著海面的霧，越往北越濃）＋ 海面 `lanterns`（漂流的小水燈，往北漂）。
- **BGM**：`dream`（0-7 少女出現時漸弱，只剩「渡魂謠」主旋律的 dizi 獨奏，見 0-7）。
- **特殊繪製**：`drawOver` 在畫面最上方（y < 0 的天空）畫一座極遠的燈塔剪影，燈光以約 4 秒週期「亮 → 暗 → 幾乎熄滅 → 掙扎著亮起」。這是彼岸燈正在衰弱的第一個視覺暗示。

## 2. 燈魂（可對話的物件）

燈魂是溺死在黑水溝裡的亡魂所化的小燈。它們不知道自己在哪，也不知道星河是誰；它們說的話是全遊戲主題的第一次低語。對話框名字一律顯示「漂流的燈」，無頭像；文字以淡藍色顯示（`o.color:'#bfefff'`，若對話系統支援）。每個燈魂可重複對話；第二次起說「再說一次」的台詞。

### 燈魂A「唐山阿伯」— (7,38)
- 第一次：
  - 漂流的燈：「唐山……唐山在哪一邊？」
  - 漂流的燈：「我答應過阿娘，賺了錢就回去的。」
  - 漂流的燈：「六死三留一回頭……少年仔，你講，我是哪一個？」
  - 星河(think)：「……阿伯，我不知道。」
  - 漂流的燈：「不知道好，不知道好……知道了，就回不去了。」
- 再次：
  - 漂流的燈：「海水好鹹……鹹到心肝底去了。」

### 燈魂B「婦人」— (5,25)
- 第一次：
  - 漂流的燈：「孩子，你怎麼一個人在橋上？」
  - 漂流的燈：「……咦？你身上，怎麼沒有燈？」
  - 星河(surprise)：「燈？什麼燈？」
  - 漂流的燈：「每個人都有一盞的。就像我這樣，小小的，暖暖的……」
  - 漂流的燈：「你的……在哪裡呢？」
  - [燈魂慢慢漂遠一格，又漂回來。]
- 再次：
  - 漂流的燈：「快回去吧。這裡不是活人來的地方。」

### 燈魂C「孩子」— (15,27)
- 第一次：
  - 漂流的燈：「大哥哥，前面好暗喔。」
  - 漂流的燈：「以前一直往前漂，就會看到光。阿嬤說，那叫做『彼岸』。」
  - 漂流的燈：「可是現在……燈好像累了。」
  - 星河(sad)：「……別怕，哥哥去前面看看。」
- 再次：
  - 漂流的燈：「大哥哥，你身上暖暖的。我可以跟著你一下嗎？」
  - [燈魂C 跟在星河身後漂浮直到 0-6（純裝飾，`follow` 一般 NPC 不阻擋）；0-6 霧起時它驚慌地漂走。若實作麻煩可省略跟隨。]

### 燈魂D「漁夫」— (13,13)
- 第一次：
  - 漂流的燈：「浪越來越大了。」
  - 漂流的燈：「我在海上討了一世人的生活，從來沒看過海這麼黑。」
  - 漂流的燈：「從前一路有光，一路明。現在……前頭黑漆漆的。」
- 再次：
  - 漂流的燈：「那個白衫的姑娘，在前頭站好久了。好像在等人，又好像……在跟誰告別。」

   - 「那裡有一座燈，叫做——彼岸燈。」

### 「渡魂謠」歌詞（全遊戲共用設定，供其他章節作者參考）
白芷的歌一共有數段，隨著她找回記憶逐段出現。序章與第一章已使用前兩段：

> （一）燈一盞，渡一人，黑水茫茫莫回身；前塵如霧隨潮去，彼岸花開又一春。
> （二）燈兩盞，渡兩人，岸上有人喚你名；莫怕夜長風浪急，一路有光一路明。

（建議後續章節延續「燈三盞，渡三人……」的格式，最後一段在真結局翻轉為「千盞燈」。）
